## 适用与排除

- 适用：上述本次需求涉及的用户端页面、弹窗、描述组件和两个选择表格。
- 非运输排放源：共享描述区域适用；运输类型：既有 `hidden={isTransport}` 和字段隐藏条件保留，不新增描述或匹配请求。
- 模型检查侧栏：仅主排放源 `checkModelData && visible` 分支适用；新共享抽屉没有此侧栏，不向其注入。
- 只读、分享、禁用、权限、保存/取消及智能匹配逻辑均未在本轮修改。
- Ant Modal/Drawer 自带视口最大宽度；固定 `width={1200}`/`width={728}` 不是单独的溢出证据，未据此重设全局容器。
- `100vh`/`100dvh` 两条上限为浏览器回退，保留；未当作重复声明删除。
- 后端、接口、数据库、子模块、全局主题与全局组件未修改；未新增单元测试。
